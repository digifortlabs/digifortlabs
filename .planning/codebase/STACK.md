# Technology Stack

## Frontend
- **Framework**: Next.js 16.1.6 (React 19.2.3)
- **Styling**: Tailwind CSS 4, Radix UI, Lucide Icons
- **Visualization**: Recharts, Three.js
- **Utilities**: jspdf, react-pdf, react-qr-code, react-webcam
- **Language**: TypeScript

## Backend
- **Framework**: Python / Flask
- **Database**: PostgreSQL (psycopg2)
- **Authentication**: PyJWT
- **Storage**: AWS S3
- **Server**: Gunicorn
- **Language**: Python

## Infrastructure
- **Containerization**: Docker / Docker Compose
- **Web Server**: Nginx
- **Cloud**: AWS (EC2, S3)
- **Deployment**: Custom Bash/PowerShell scripts
