Establish the core asynchronous processing pipeline for heavy-duty PDF optimization tasks.

## Objectives

- Initialize the Celery application.
- Implement a `StorageService` to manage temporary job files.
- Verify end-to-end task queuing and execution.

<task id="2.1.2">

<action>
Create `backend/app/core/celery_app.py` with the following:
```python
from celery import Celery
from app.core.config import settings

celery_app = Celery(
    "digifort_tasks",
    broker=settings.CELERY_BROKER_URL,
    backend=settings.CELERY_RESULT_BACKEND
)

celery_app.conf.update(
    task_serializer="json",
    accept_content=["json"],
    result_serializer="json",
    timezone="UTC",
    enable_utc=True,
    task_track_started=True,
    task_time_limit=3600, # 1 hour max
)

celery_app.autodiscover_tasks(["app.tasks"])
```
</action>
<acceptance_criteria>
- `backend/app/core/celery_app.py` exists.
- `celery_app.autodiscover_tasks` points to `app.tasks`.
</acceptance_criteria>
</task>
