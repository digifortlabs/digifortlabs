# Phase 3 Plan 1: High-Density Compression Engine

Implement the core PDF optimization engine to achieve "clean and sharp" compression (~500KB target) for clinical documents.

## Proposed Changes

### [Backend] Dependencies & Configuration

#### [MODIFY] [config.py](file:///d:/Website/DIGIFORTLABS/backend/app/core/config.py)
- Ensure `GHOSTSCRIPT_CMD` and `TESSERACT_CMD` are correctly pointed to existing binaries.
- Add `DEFAULT_COMPRESSION_STRATEGY` (default: `BALANCED`).

### [Backend] Compression Engine

#### [NEW] [compression.py](file:///d:/Website/DIGIFORTLABS/backend/app/services/compression.py)
- **`CompressionService`**:
  - `compress_pdf(input_path: Path, output_path: Path, level: str)`: Main entry point.
  - `_run_gs(input_path, output_path, settings)`: Helper for Ghostscript calls.
  - `_run_ocrmypdf(input_path, output_path, args)`: Helper for OCRmyPDF calls.
- **Strategies**:
  - `FAST`: `pikepdf` optimization (stripping objects, metadata).
  - `BALANCED`: Ghostscript `-dPDFSETTINGS=/ebook` (150 DPI).
  - `ULTRA`: `ocrmypdf` with `--optimize 3` and `--deskew`.

### [Backend] Task Integration

#### [MODIFY] [optimization.py](file:///d:/Website/DIGIFORTLABS/backend/app/tasks/optimization.py)
- Update the Celery task to call `CompressionService`.
- Add error handling and fallback to a lower level if a tool fails.
